# Установка

[English](INSTALL.md) · [Українська](INSTALL.uk.md) · **Русский**

## Коротко

1. Скачай **`ClaudeTelegram-Setup.exe`** со
   [страницы релизов](https://github.com/bonuxq/claude-telegram-bridge/releases)
   и запусти.
2. Виджет сам откроет экран настройки. Пройди пять шагов в нём.

Это вся установка. Никакого Python, терминала и правки файлов — установщик
несёт рантайм с собой и сам прописывает хуки Claude Code.

Только Windows. Демон и хуки — обычный Python и работали бы где угодно, но
виджет построен на Win32 API, и порта нет.

---

## Что делает установщик

- Ставит в `%LOCALAPPDATA%\ClaudeTelegram` — **без прав администратора**.
  За пределы твоего профиля он не пишет ничего.
- Прописывает хуки и статус-строку в `~/.claude/settings.json`, оставляя
  резервную копию с отметкой времени и не трогая твои собственные хуки.
- По галочке — запуск моста при входе в систему.
- В конце поднимает демон и виджет.

Удаление убирает хуки и саму программу, но оставляет `config.json`:
переустановка не должна стоить тебе токена и списка проектов.

## Экран настройки

Открывается сам на свежей установке, потом живёт в меню виджета под пунктом
**Telegram…**.

### 1. Создать бота

Нажми **Открыть @BotFather**, отправь ему `/newbot`, придумай имя и username.
В ответ он выдаст токен вида `1234567890:AAF...`.

### 2. Вставить токен

В поле, потом **Сохранить и проверить**. Мост спрашивает у Telegram, рабочий
ли токен, ещё до сохранения, так что результат виден сразу:

- `Бот @твойбот на связи` — готово.
- `Telegram не принял этот токен` — он неверный или отозван; мост оставит
  старый, а не сохранит сломанный.

### 3. Создать группу

**Супергруппу**, не обычную группу и не канал. В её настройках включи
**Темы** (Topics) — мост даёт каждому проекту свою тему, без них разделять
нечего.

### 4. Добавить бота администратором

Без прав администратора он не создаст темы. Статус админа заодно позволяет
ему читать обычные сообщения — поэтому настройка приватности у BotFather
роли не играет.

### 5. Привязать группу

Отправь в группе `/register`. Бот подтвердит, и темы **«Статус Claude»** и
**«Лимиты Claude»** появятся сами.

Привязка намеренно односторонняя: после неё `/register` из любого другого
чата игнорируется, так что найти твоего бота недостаточно, чтобы увести его
отчёты. Чтобы перенести мост в другую группу, сначала отправь `/unregister`
в текущей.

### 6. Хуки

Экран настройки показывает, на месте ли они, и ставит их одной кнопкой.
Установщик уже сделал это, так что обычно там просто написано
`Хуки Claude Code установлены`.

**Перезапусти окна VSCode, открытые во время установки** — хуки
подхватываются при старте окна.

## Выбор проектов

Пути вводить не нужно. Меню виджета → **«Проекты…»** или `/projects` в чате:
появится список проектов, которые Claude Code уже знает, свежие сверху.
Отмеченные получают свою тему в Telegram.

Этот список — граница приватности: **неотмеченный проект не отправляет
ничего**.

## Запуск из исходников

Если бинарник запускать не хочется:

```bash
git clone https://github.com/bonuxq/claude-telegram-bridge
cd claude-telegram-bridge
cp config.example.json config.json
python install.py                 # хуки и статус-строка
python -m claudetg.daemon         # демон
python widget.pyw                 # виджет
```

Python 3.9+ и больше ничего — весь мост на стандартной библиотеке. Экран
настройки из исходников работает точно так же.

Собрать установщик самому:

```bash
pip install pyinstaller
python -m PyInstaller claudetg.spec --noconfirm
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss
```

## Если что-то не работает

**В Telegram тишина.** Сначала посмотри экран настройки: он говорит, принят
ли токен, привязана ли группа и установлены ли хуки. Эти три пункта
покрывают почти всё.

**Хуки не срабатывают.** Окно VSCode, открытое до установки, обычно
подхватывает их на лету, но не всегда. Перезапусти окно.

**Тема проекта не появилась.** Тема создаётся при первом событии от сессии.
Внутри длинного хода событий нет — мост говорит на границах хода.

**Лимиты пустые.** Claude Code рисует статус-строку только в своём
терминальном интерфейсе, поэтому при работе через VSCode её никто не
вызывает. Включи **«Опрашивать лимиты самому»** в «Функциях» — демон станет
запрашивать их напрямую раз в 30 секунд. Подробности — в
[FEATURES.ru.md](FEATURES.ru.md#когда-статус-строка-не-запускается--usage_poll).

**Демон не отвечает.** Смотри `daemon.log` рядом с исполняемым файлом. Если
порт 8787 занят — демон уже запущен, второй не нужен. Виджет пишет свои
падения в `widget.log` там же.

**Windows пишет «неизвестный издатель».** Сборка пока не подписана. Можно
проверить исходники и собрать самому командами выше.

## Безопасность

- `config.json` содержит токен бота. Утёкший токен даёт постороннему читать
  твои уведомления и писать в твою группу.
- Мост отправляет в Telegram содержимое работы: текст ответов, ошибки,
  списки задач. В чат попадает только то, что относится к **отмеченным**
  проектам.
- `auto_discover` подключает любой проект автоматически — удобно, но тогда
  наружу пойдёт содержимое всех сессий на машине.
- `spawn` (по умолчанию выключен) запускает агента по сообщению из Telegram.
  Это выполнение кода на твоей машине по сообщению в чате, так что утёкший
  токен становится правом запустить агента в твоих проектах.
- `usage_poll` (по умолчанию выключен) — единственное место, которое трогает
  учётные данные: читает OAuth-токен Claude Code, чтобы спросить лимиты у
  Anthropic.
